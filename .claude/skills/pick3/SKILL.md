# pick3 — 오늘 파볼 글 3개

초점(선택): $ARGUMENTS

## 절차

1. `git pull -q --ff-only origin main` 후 `npm run news` 를 실행해 최근 2일치 목록을 받는다. 목록이 비면 그렇게 말하고 끝.
2. **제목·소스·점수만 보고 고른다.** 본문은 아직 모른다 — 내용을 아는 것처럼 요약·추측하지 않는다.
3. 세 자리를 서로 다른 기준으로 채운다.
   - **판이 갈리는 글** — 교차소스 겹침(×N) 또는 HN 댓글 수가 점수에 비해 많은 글. 댓글 토론이 재료.
   - **실력이 느는 글** — 저빈도 블로그(Brooker·matklad·Eaton·Fowler)·LWN·HF Papers 에서 하나. 없으면 Cloudflare·Willison.
   - **내 일과 닿는 글** — 초점이 주어졌으면 그것, 없으면 이 저장소(TypeScript·수집·정적 사이트·RAG 관심)와 연결되는 글.
   - 뉴스·정치·기업 가십·인사 소식은 제외한다. 화제여도 파서 남는 게 없다.
4. 출력은 딱 이 형식. 항목당 두 줄, 부연 금지.
   ```
   N. 제목  [소스]
      왜: 한 줄 (어떤 기준으로 골랐고, 파면 뭐가 남는지)
   ```
   마지막에 한 줄: "번호를 고르면 dig 해서 바로 토의합니다."
5. 사용자가 고르면 `npm run news -- dig <번호>` 를 돌려 생성된 `dig/*.md` 를 읽고, 세 줄로 연다: 글의 실제 주장 / HN 댓글의 가장 강한 반박 / 사용자 프로젝트와 닿는 지점. 그 뒤는 대화.
